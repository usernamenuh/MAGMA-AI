# Catatan untuk kontributor yang memakai coding agent

Mulai dari [README.md](../README.md) untuk memahami sistem. Jalankan proyek melalui [panduan pemasangan](INSTALLATION_GUIDE.md), lalu gunakan [panduan pengujian backend](../ms-esdm/documentations/TESTING.md) saat mengubah API atau worker.

Catatan audit historis tidak menggambarkan status implementasi saat ini. Periksa kode dan `docker-compose.yml` sebelum memakai klaim teknis dari catatan tersebut. Jangan masukkan `.env`, isi `data/`, token n8n/Evolution, atau QR WhatsApp ke commit.
